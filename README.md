# portfolio-optimization
A Python-based portfolio optimization tool that analyzes NSE stock data to balance risk and returns and generate optimized investment allocations.

##  About the Project

What if we could take raw stock-market data and use it to figure out how much money should be invested in each stock?

That was the main idea behind this project.

This project is a Python-based portfolio optimization tool that uses historical NSE stock-price data to analyse risk and return and generate an optimized portfolio based on an investor's preferences.

The goal was not just to find stocks with high returns, but to understand how different stocks behave together and use that information to build a more balanced portfolio.

---

##  Problem Statement

Choosing stocks for a portfolio is not only about finding stocks with high returns.

An investor also needs to think about:

- How risky each stock is
- How stocks move in relation to each other
- How much risk the overall portfolio carries
- How much money should be invested in each stock

- ##  What Does the Project Do?

The application:

- Fetches historical NSE stock data
- Calculates stock returns
- Measures risk using VaR (95%)
- Analyses expected returns
- Studies correlation between stocks
- Calculates covariance
- Finds an optimized portfolio allocation
- Shows portfolio risk and expected return
- Calculates how much money can be allocated to each stock
- Provides visual risk-return analysis

The application fetches stock price data from Yahoo Finance using `yfinance`.

---
## Our Approach

We created a system that takes historical stock-price data and goes through several stages:

Stock Market Data
        ↓
Risk & Return Analysis
        ↓
Correlation & Covariance
        ↓
Selection of Suitable Stocks
        ↓
Portfolio Optimization
        ↓
Optimal Portfolio Weights
        ↓
Investment Allocation


## Interactive Interface

We also wanted the project to be useful for someone who does not know Python.

So, we created a simple web-based interface where a user can enter:

- Years of historical data
- Risk calculation period
- Expected return period
- Target risk
- Target return
- Number of stocks to consider
- Investment amount

The system then performs the analysis and displays the portfolio results without requiring the user to write code.

These figures are an example output from one run of the application and can change depending on the selected inputs and market data.

## What We Learned

One of the biggest things we learned from this project is that portfolio construction is not simply about selecting stocks with the highest returns.

The way stocks move in relation to each other can have a major impact on overall portfolio risk. By looking at correlation, covariance, and portfolio-level risk, we were able to understand how diversification can affect the final allocation.

This project also helped us connect concepts from Portfolio Management and Financial Analytics with practical Python-based data analysis.
